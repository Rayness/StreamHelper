# StreamHelper

Десктоп-приложение для стримеров (Windows, Electron + TypeScript): всё для трансляции в одном окне.

- **Объединённый чат** — сообщения с эмоутами Twitch/7TV/BTTV/FFZ и значками, ответы, удаление, таймаут, бан.
- **Алерты** — фоллоу, подписки, продления, подарочные подписки, битсы, рейды, донаты, награды за баллы. Свои звуки, картинки/видео, анимации, пороги сумм, озвучка (TTS), очередь с паузой и пропуском.
- **Оверлеи для OBS** (Browser Source): алерты, чат, лента событий, цели, таймеры (обратный отсчёт, секундомер, сабатон), баннеры (бегущая строка, карточка, плашка; показ по расписанию), лейблы («последний фолловер», «топ-донат», счётчики), дождь из эмоутов, «Сейчас смотрим на Kawaki». Каждый оверлей — с живым превью и кнопкой «Добавить в OBS» (источник создаётся в текущей сцене нужного размера).
- **Интерактив** — колесо удачи (веса секторов, команда в чате, награда за баллы, хоткей), голосование в чате, розыгрыш по ключевому слову с билетами для подписчиков, аниме-квиз «угадай по кадру» на каталоге Kawaki.
- **Босс чата** — совместная битва зрителей: команда в чате или награда за баллы наносит урон, для каждого зрителя действует кулдаун, на оверлее видны здоровье и последние удары.
- **Графическая реклама** — отдельный оверлей для готовых изображений и видео партнёров: размещение в углу, ручной показ и ротация по расписанию во время эфира. Старые текстовые баннеры доступны отдельно.
- **Дополнительные оверлеи** — статус эфира с числом зрителей и таймером, выделенное сообщение из чата.
- **Док-панель OBS** — управление сценами, эфиром, записью, алертами, интерактивом, рекламой и быстрыми действиями прямо в OBS.
- **Kawaki** — вход через device flow (`kawaki.ru/link`), оверлей и команда `!аниме` с тем, что сейчас играет, автоназвание трансляции по шаблону, ссылка на партнёрский эфир.
- **Палитра команд** (Ctrl+K) — переход куда угодно и запуск чего угодно с клавиатуры.
- **Чат-бот** — свои команды с переменными и кулдаунами, встроенные команды (`!аптайм`, `!followage`, `!title`, `!game`, `!so`, `!count`, `!permit`), таймерные сообщения, счётчики, автомодерация (ссылки, капс, запрещённые слова, спам), реакции на события.
- **Управление трансляцией** — название и категория Twitch, сцены/источники/звук/стрим/запись OBS, кнопки быстрых действий и глобальные горячие клавиши.
- **Донаты** — DonationAlerts и Streamlabs.
- Интерфейс на русском и английском.

Платформы: сейчас Twitch. YouTube, VK Play Live и Kick подключаются через интерфейс `ChatPlatform` ([src/main/platforms/types.ts](src/main/platforms/types.ts)).

## Перед первым релизом: регистрация приложений

Приложение ходит в API от имени зарегистрированных клиентов. Их нужно создать один раз (автору приложения, а не каждому стримеру) и вписать Client ID в [src/shared/defaults.ts](src/shared/defaults.ts):

| Сервис | Где создать | Настройки | Куда вписать |
|---|---|---|---|
| Twitch | https://dev.twitch.tv/console/apps | Client Type: **Public**, OAuth Redirect URL: `http://localhost` | `DEFAULT_TWITCH_CLIENT_ID` |
| DonationAlerts | https://www.donationalerts.com/application/clients | Redirect URI: `http://127.0.0.1:4848/auth/donationalerts` | `DEFAULT_DA_CLIENT_ID` |

Пока константы пустые, Client ID можно ввести прямо в приложении (Подключения / Настройки → Дополнительно).

Секреты приложений не нужны: Twitch — Device Code Flow для публичных клиентов, DonationAlerts — Implicit Grant. Streamlabs не требует регистрации: стример вставляет свой Socket API Token.


## Док-панель OBS

Откройте в StreamHelper «OBS и действия» → «Док-панель StreamHelper для OBS» и скопируйте адрес. В OBS выберите **Вид → Док-панели → Настраиваемые док-панели браузера**, задайте имя `StreamHelper` и вставьте адрес. URL содержит случайный ключ доступа и хранится в зашифрованном `secrets.bin`; не публикуйте его. Приложение должно оставаться запущенным (можно свернуть в трей). Если поменять порт оверлеев, обновите адрес в OBS.

## Автообновление

Установленная Windows-версия проверяет обновления после запуска и каждые 6 часов, загружает доступный выпуск в фоне и предлагает установку в «Настройках». Стример сам выбирает момент перезапуска, чтобы обновление не прерывало эфир. Источник обновлений — публичный репозиторий `Rayness/StreamHelper-Releases` с готовыми файлами; исходники могут оставаться приватными. Сборка `npm run dist` создаёт файлы локально и ничего не публикует. Для выпуска создайте публичный репозиторий с этим именем, соберите версию и запустите `powershell -File scripts/publish-release.ps1`; скрипт проверяет номер версии и публикует установщик, blockmap и `latest.yml`. Версию 0.2.0 и более ранние необходимо один раз обновить вручную, поскольку в них нет клиента автообновления.

Подводные камни окружения:
- Если `npm install` не скачал Electron (`Error: Electron uninstall`), выполните `node node_modules/electron/install.js`.
- Терминал VS Code выставляет `ELECTRON_RUN_AS_NODE=1`, и Electron стартует как голый Node (`electron.app` undefined). Запускайте из обычного терминала или сбросьте переменную: `env -u ELECTRON_RUN_AS_NODE npm run dev` (PowerShell: `Remove-Item Env:ELECTRON_RUN_AS_NODE`).

## Архитектура

```
src/
  shared/       типы (события, настройки, IPC-контракт), шаблоны, дефолты — общие для main, UI и оверлеев
  main/         Electron main process
    core/       шина событий, настройки (JSON), секреты (safeStorage/DPAPI), состояние подключений
    platforms/  ChatPlatform + Twitch: Device Code OAuth, Helix, EventSub WebSocket, нормализация событий
    donations/  DonationAlerts (OAuth + Centrifugo), Streamlabs (socket.io v2)
    obs/        obs-websocket v5
    bot/        команды, кулдауны, права, модерация, таймеры
    features/   очередь алертов, цели/таймеры/сабатон, статистика и переменные шаблонов, баннеры и лейблы,
                колесо, голосование, розыгрыш, квиз, эмоуты, действия и глобальные хоткеи, история чата
    integrations/kawaki/  клиент Kawaki API v1: device flow, ротация refresh-токенов, «сейчас смотрю», партнёры
    overlay/    локальный HTTP+WS сервер (127.0.0.1:4848) для оверлеев и OAuth-колбэка
  preload/      мост window.api
  renderer/     React UI
resources/overlays/  оверлеи для OBS (чистые HTML/JS)
tests/          unit + интеграционные тесты (фейковые серверы OBS и EventSub, моки Helix)
```

Kawaki: «что играет» берётся из `GET /api/v1/me/now-watching` (добавлен в AniSub для StreamHelper). Пока он не задеплоен (404), приложение само переключается на последний тайтл из списка «Смотрю» — без номера серии в реальном времени и без автоназвания трансляции.

Нагрузка: само приложение в простое — около 300 МБ памяти и доли процента CPU. Каждый оверлей в OBS — отдельный процесс браузера (~40–60 МБ); статичные оверлеи почти не тратят CPU, постоянно движущиеся (бегущая строка) стоят заметную долю ядра на композитинг, поэтому анимации сделаны на CSS/Web Animations, а не покадровым JS.

Поток данных: платформы и донат-сервисы нормализуют всё в `ChatMessage` / `StreamEvent` и публикуют в `EventBus`. На шину подписаны бот, очередь алертов, цели/сабатон, хаб оверлеев и UI — ни один из них не знает, откуда пришло событие.

Файлы пользователя лежат в `%APPDATA%/StreamHelper`: `settings.json` (настройки), `secrets.bin` (токены, зашифрованы DPAPI), `media/` (звуки и картинки алертов).
