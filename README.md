# StreamHelper

[Русский](README.md) · [English](README.en.md)

StreamHelper — приложение для Windows, которое собирает управление стримом, чат и источники OBS в одном окне. Текущая версия: **0.12.0**. Интерфейс доступен на русском и английском.

В выпуске **0.12.0**: выбор шрифта во всех модулях (30 встроенных шрифтов, системные и Google Fonts), модуль «Донаты», группа StreamHelper и отдельные настройки для каждой сцены OBS, вкладки «Конструктор» (свои оверлеи) и «Переменные», вход в Kawaki в «Подключениях», а также набор «Инструменты стрима»: автоклипер, проклятия, музыкальная дуэль, «Угадай мелодию», приглушение музыки, биржа зрителей, портал, итоги стрима и щит от рейда. [Изменения и результаты проверок](docs/verification-0.12.0.md).

> **При обновлении с 0.11.x:** «Добавить в OBS» теперь кладёт источник во вложенную сцену «StreamHelper · <сцена>». Уже добавленные источники остаются на месте; собрать их в группу можно кнопкой в модуле OBS, а отключить группу — в **Подключениях → OBS**. Для клипов и щита от рейда переподключите Twitch.

Релизы доступны [в этом репозитории](https://github.com/Rayness/StreamHelper/releases) и в [публичном репозитории обновлений](https://github.com/Rayness/StreamHelper-Releases/releases).

## Скачать и начать работу

1. Скачайте `StreamHelper-Setup-0.12.0.exe` из [выпуска 0.12.0](https://github.com/Rayness/StreamHelper/releases/tag/v0.12.0) или [репозитория обновлений](https://github.com/Rayness/StreamHelper-Releases/releases/tag/v0.12.0). Установщик Windows пока не подписан сертификатом издателя.
2. Откройте **Подключения → Twitch** и войдите как вещатель. Авторизация проходит через код на сайте Twitch.
3. При необходимости откройте **Подключения → OBS** и укажите адрес, порт и пароль WebSocket. По умолчанию порт — 4455.
4. Добавьте нужные функции: алерты, чат, заказ музыки или отдельные игры. Выберите добавленный модуль, настройте его и используйте **Добавить в OBS** для браузерного источника.
5. Следите за прогрессом на **Панели**: в режиме «Настроить панель» перетаскивайте блоки за заголовок, меняйте размер за правый нижний угол и выбирайте, какие блоки видны. Отдельный аккаунт бота подключается в **Подключения → Twitch → Аккаунт бота**.

Приложение должно работать во время эфира: локальный сервер на `127.0.0.1` отдаёт оверлеи и обновляет их через WebSocket. По умолчанию порт сервера — 4848; его можно изменить в **Параметрах приложения**. При закрытии окна StreamHelper может оставаться в системном трее.

### Что где находится

| Место | Возможности |
| --- | --- |
| Рабочая область | Добавление и настройка только выбранных модулей. У каждого профиля свой список. |
| Подключения | Twitch, аккаунт бота, OBS и сервисы донатов. Общие для всех профилей. |
| Панель | Состояние и прогресс. Свободная сетка: блоки не перекрываются, раскладка сохраняется в профиле. |
| Выбор профиля | Создание чистого профиля или копии, переименование, переключение и удаление. |
| Параметры приложения | Оформление (тема, акцент, стекло, плотность, масштаб), язык, валюта, работа в трее, порт локального сервера, обновления и список горячих клавиш. Оформление общее для всех профилей. |

Горячие клавиши: `Ctrl+1`/`Ctrl+2`/`Ctrl+3` — рабочая область, панель, подключения; `Ctrl+,` — параметры; `Ctrl+Shift+L` — светлая или тёмная тема. `Ctrl+K` ищет только добавленные модули и их действия. Удалённый модуль нельзя настроить через поиск или старую ссылку; его настройки и прогресс сохраняются.

## Оверлеи

Все оверлеи работают как отдельные источники браузера OBS. В добавленном модуле виджета есть рекомендованный размер, предпросмотр и индикатор подключённых источников.

| Источник | Что показывает |
| --- | --- |
| Алерты | Фолловы, подписки, битсы, рейды, донаты и награды. |
| Чат | Сообщения, эмоуты, значки, время, контекст ответа и настраиваемые анимации. Есть подложки «карточка», «стекло», градиент, контур, неон, полосы, реплика и прозрачный стиль; можно добавить свою картинку. |
| Последние события | Компактная лента активности канала. |
| Награды за баллы | Последние пользовательские награды Twitch: зритель, название, стоимость и, при желании, его ответ. |
| Коллаб | Список каналов участников совместного эфира и входящие рейды. Список каналов заполняется вручную. |
| Сейчас играет | Трек, исполнитель, обложка, альбом и прогресс из медиасеансов Windows. Поддерживаются Spotify, приложение Яндекс Музыки и плееры браузера. |
| Заказ музыки | YouTube-плеер и очередь: награда Twitch, донат, команды `!sr`/`!songrequest` и ручное добавление. |
| Бегущая строка | Текст, карточка или плашка с расписанием показа. |
| Баннер | Изображения и видео партнёров с отдельным расписанием и 14 эффектами появления. |
| Статус эфира и сообщение на экране | Название, игра, зрители, время эфира; отдельный источник для выделенного сообщения чата. |
| Цели, таймеры и лейблы | Прогресс донатов, фолловеров и подписок, новые цели по сообщениям и участникам чата, сабатон и текстовые переменные. |
| Счётчик | Счётчик бота (смерти, победы…) в виде карточки, текста или значка. |
| Шкала хайпа | Заполняется от фолловов, подписок, битсов, донатов, рейдов, наград и чата, постепенно остывает, есть уровни. |
| Топ чата | Самые активные зрители эфира; боты не учитываются. |
| Интерактивные источники | Колесо, голосование, розыгрыш, очередь зрителей, «Угадай число», босс, квиз и дождь эмоутов. |
| Kawaki | Что сейчас смотрите: постер, название и прогресс. |

**Баллы канала:** StreamHelper получает событие `channel.channel_points_custom_reward_redemption.add` от Twitch, если у подключённого вещателя доступны пользовательские награды и разрешён доступ `channel:read:redemptions`. Встроенные награды Twitch не попадают в эту ленту. Название награды можно привязать к колесу, удару по боссу или быстрому действию. Если Twitch не предоставляет это событие, оверлей остаётся пустым; остальные функции работают.

**Коллабы:** добавьте Twitch-каналы гостей по одному на строку. Карточка обновляется без перезагрузки OBS. Входящие рейды показываются автоматически, если подключение Twitch передаёт их события. Совместный чат или управление чужими каналами не подключаются автоматически.

**Музыка:** откройте **Оверлеи → Сейчас играет** и добавьте источник в OBS. В режиме «Авто» приложение выбирает играющий сеанс, отдавая приоритет Spotify, затем приложению Яндекс Музыки и браузеру. Можно закрепить источник, выбрать горизонтальную или вертикальную карточку, размер обложки и текста, прозрачность фона, цвет, показ источника, альбома и прогресса. При паузе карточка по умолчанию скрывается. Вход в Spotify или Яндекс Музыку через StreamHelper не нужен: данные берутся из медиасеансов Windows. Яндекс Музыка в Chrome или Edge определяется как «Браузер», поскольку Windows не сообщает адрес вкладки. Если одновременно играют несколько вкладок одного браузера, выбрать конкретную вкладку нельзя.

**Заказ музыки:** откройте **Оверлеи → Заказ музыки**, добавьте отдельный источник браузера в OBS и включите приём заказов. Укажите точное название пользовательской награды Twitch: зритель вводит ссылку на отдельное видео YouTube. Для доната задайте минимальную сумму в основной валюте; ссылка должна быть в тексте сообщения. Поддерживаются DonationAlerts, Streamlabs и StreamElements. Очередь сохраняется между запусками, треки переключаются автоматически либо вручную в приложении и OBS док-панели. Можно выбрать полноэкранное видео, компактное видео рядом с данными заказа или режим «только очередь» без видео и звука YouTube в OBS. Также доступны громкость, кнопки плеера, имя заказчика, название видео, длина очереди, положение и размер компактного видео, цвет и прозрачность. Для воспроизведения YouTube видео должно оставаться видимым; в режиме «только очередь» заказы ждут, пока вы переключите плеер обратно или запустите их в другом плеере. При включённой настройке StreamHelper ставит активный медиасеанс Windows на паузу и возобновляет его после окончания очереди. YouTube-видео должно разрешать встраивание и быть доступным на компьютере с OBS.

Перед постановкой в очередь ссылка проверяется в YouTube: удалённые, приватные и запрещённые к встраиванию видео отклоняются, а зритель получает ответ в чате с местом в очереди или причиной отказа. Видео, которое всё же не удалось воспроизвести, пропускается. Очередью можно управлять прямо в модуле: перетаскивание, «Включить сейчас», «Поставить следующим», пауза.

**Возврат баллов:** кнопка **Создать награду в Twitch** в модуле создаёт награду, которой управляет StreamHelper. За отклонённые, невоспроизводимые и удалённые вами заказы баллы возвращаются, сыгранные отмечаются выполненными. Для этого нужен доступ `channel:manage:redemptions`: если Twitch подключён в версии до 0.11.0, переподключите его. Награду, созданную вручную в панели Twitch, приложение использовать может, но вернуть за неё баллы Twitch не разрешает.

**Кто слышит музыку:** «Только зрители», «Зрители и я» или «Только я». StreamHelper включает для них управление звуком через OBS и выставляет режим прослушивания на всех источниках «Заказ музыки» при каждом подключении к OBS, поэтому ручная настройка прослушивания этого источника в OBS перезаписывается. По умолчанию — «Только зрители». Для «Зрители и я» проверьте, что «Звук рабочего стола» в OBS не захватывает устройство прослушивания, иначе музыка попадёт в эфир дважды.

**Активности чата:** в **Оверлеи → Цели** выберите «Сообщения чата» или «Участники чата». Команды бота и сообщения самого приложения не учитываются. Участники считаются по одному разу на цель; обнуление счётчика сбрасывает список участников.

**Профили:** откройте выбор профиля слева. **Новый профиль** начнётся с пустой области и стандартных настроек функций; **Создать копию** сохранит текущий набор. Модули, раскладка панели и настройки функций независимы между профилями. Подключения сервисов общие.

**Сообщения на экране:** в **Оверлеи → Сообщение на экране** выберите одиночную карточку, стопку или падающие сообщения. Для падения настраиваются сила тяжести и отскок. Можно автоматически показывать выделенные сообщения Twitch и тестировать эффект без эфира. Для полноэкранного падения создайте источник браузера размером 1920×1080.

**Донаты:** в **Алерты → Донат** добавьте уровни по сумме. Каждый уровень может иметь отдельный текст, медиа, звук и анимацию; применяется наибольший подходящий порог. Положение алерта задаётся координатами, шириной и точкой привязки, в том числе для отдельного уровня. Для цели по донатам можно выбрать источники, минимальную сумму и предел вклада одного доната.

## Подключения и автоматизация

| Сервис | Настройка |
| --- | --- |
| Twitch | Вход вещателя через Device Code Flow; отдельный вход для бота при необходимости. Приложение получает чат, события EventSub и сведения об эфире. |
| OBS Studio | Локальный obs-websocket v5. Включите сервер WebSocket в OBS и укажите адрес, порт и пароль в его модуле рабочей области. |
| DonationAlerts | Авторизуйте аккаунт через приложение. Если встроенный Client ID недоступен, укажите свой в дополнительных настройках. |
| Streamlabs | Вставьте Socket API Token своего аккаунта. |
| StreamElements | Вставьте Channel ID и JWT из панели StreamElements → Account → Channels. Учитываются завершённые разрешённые донаты Astro. |
| Streamer.bot | Включите HTTP Server в Streamer.bot, укажите порт (обычно 7474) в его модуле рабочей области. Действия можно назначить на быстрые кнопки, хоткеи и награды за баллы. |
| Discord | Создайте webhook текстового канала и вставьте URL. Можно включить анонс эфира и уведомления о донатах; есть тестовая отправка. |
| Kawaki | Войдите через `kawaki.ru/link`. Доступны «сейчас смотрим», команда `!аниме` и шаблон названия эфира. Если данные плеера недоступны, используется последний тайтл из списка «Смотрю». |
| SubForStream | Запустите SubForStream, затем в **OBS и действия** включите интеграцию и укажите его локальный порт (обычно 5000). Приложение добавляет источник субтитров в OBS и позволяет очистить их. |

Сейчас платформа чата — Twitch. В коде есть интерфейс `ChatPlatform` для будущих подключений YouTube, VK Play Live и Kick, но их рабочие коннекторы ещё не реализованы.

### Док-панель OBS

В StreamHelper откройте **OBS и действия → Док-панель StreamHelper для OBS** и скопируйте адрес. В OBS выберите **Вид → Док-панели → Настраиваемые док-панели браузера**, задайте имя и вставьте URL. В доке есть вкладки эфира, событий, интерактива и инструментов: доступны переключение профилей, сцены и источники OBS, звук, алерты, сообщения на экране, цели, таймеры, колесо, квиз, музыка и другие действия. URL содержит случайный ключ доступа: храните его как пароль и обновите в OBS, если измените порт оверлеев.

## Обновления и данные

Начиная с 0.4.x установленная версия проверяет обновления при запуске и каждые шесть часов. Загрузка идёт в фоне; установку и перезапуск вы запускаете в **Настройках**, когда эфир не прервётся. Файлы обновления публикуются в [публичном репозитории выпусков](https://github.com/Rayness/StreamHelper-Releases/releases). Версии 0.2.0 и старее нужно один раз обновить установщиком вручную.

Данные пользователя находятся в `%APPDATA%\StreamHelper`: `settings.json` содержит настройки, `secrets.bin` — токены, зашифрованные средствами Windows, `media/` — импортированные звуки, изображения и видео. Для переноса настроек закройте приложение и скопируйте эту папку; перенос `secrets.bin` между разными пользователями Windows может потребовать повторного входа в сервисы.

Локальный сервер привязан к `127.0.0.1`. URL док-панели защищён отдельным ключом. Обычные URL оверлеев предназначены для локального OBS: не публикуйте порт сервера в интернет без своей защиты.

## Частые проблемы

- **Пустой оверлей:** проверьте, что StreamHelper открыт, URL источника совпадает с текущим портом и в OBS включено обновление страницы источника. Некоторые источники ждут события или ручного показа.
- **Нет наград за баллы:** войдите как вещатель повторно, чтобы Twitch выдал нужный доступ; проверьте, что в канале есть пользовательская награда. Встроенные награды не поддерживаются.
- **«Нет права управлять наградами» при создании награды:** переподключите Twitch в **Подключениях**, чтобы выдать доступ `channel:manage:redemptions`.
- **Музыка из заказов в эфире звучит дважды или с эхом:** в «Кто слышит музыку» выбран режим со звуком у вас, а «Звук рабочего стола» в OBS захватывает то же устройство, что и прослушивание. Выберите «Только зрители» или смените устройство прослушивания в OBS → Настройки → Аудио.
- **Нет управления OBS:** включите WebSocket Server в OBS и проверьте порт/пароль. StreamHelper управляет только подключённым OBS.
- **Не видно музыку:** запустите трек в плеере на этом же компьютере, проверьте список найденных источников и режим «Авто» или «Браузер». Некоторые плееры не публикуют медиасеанс Windows, поэтому их треки не появятся.
- **Антивирус или SmartScreen предупреждает об установщике:** сборка пока не подписана сертификатом издателя. Сверяйте файл и контрольную сумму с выпуском на GitHub.
- **После смены порта не работает док:** скопируйте новый URL из приложения и замените адрес в настройках док-панели OBS.

## Разработка

Нужны Node.js и npm, Windows для сборки установщика. Исходники — Electron, React и TypeScript.

```powershell
npm install
npm run dev
npm run typecheck
npm test
npm run build
npx electron-builder --win --publish never --config.directories.output=dist/0.8.0
```

Сгенерированные привязки Windows Runtime уже включены в репозиторий; для обычной сборки Windows SDK не нужен. Чтобы пересоздать их на машине с Windows SDK, выполните `npm run generate:winrt`. Сборка установщика остаётся локальной, пока явно не запущен скрипт публикации. Для выпуска в публичный репозиторий обновлений:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/publish-release.ps1 -ValidateOnly
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/publish-release.ps1
```

Перед выпуском убедитесь, что `package.json`, версия установщика и `latest.yml` совпадают. Скрипт проверяет наличие установщика и blockmap, а также что репозиторий обновлений публичный. Для регистрации своего Twitch-клиента используйте [Twitch Developer Console](https://dev.twitch.tv/console/apps): тип **Public**, OAuth Redirect URL `http://localhost`; Client ID задаётся в приложении или `DEFAULT_TWITCH_CLIENT_ID` в `src/shared/defaults.ts`. Для DonationAlerts создайте клиент с Redirect URI `http://127.0.0.1:4848/auth/donationalerts` и укажите Client ID. Клиентские секреты для этих потоков авторизации приложению не нужны.

Для подписанного выпуска предоставьте сертификат подписи кода Windows (`.pfx`/`.p12`) через переменные окружения `WIN_CSC_LINK` и `WIN_CSC_KEY_PASSWORD`; не добавляйте сертификат или пароль в репозиторий. Собирайте установщик с `--config.forceCodeSigning=true`. Скрипт публикации по умолчанию требует доверенную Authenticode-подпись. Владелец проекта может явно разрешить неподписанный выпуск флагом `-AllowUnsigned`; именно так выпущена версия 0.7.0. Подробности: [документация electron-builder](https://www.electron.build/v26/docs/features/code-signing/).

### Структура проекта

```text
src/shared/              типы, настройки, значения по умолчанию, шаблоны
src/main/                Electron main process, сервисы и IPC
src/main/platforms/      Twitch и интерфейс платформ чата
src/main/donations/      сервисы донатов
src/main/obs/            управление OBS
src/main/overlay/        локальный HTTP/WebSocket сервер и док-панель
src/main/features/       алерты, интерактив, реклама, статистика и действия
src/renderer/            интерфейс React
resources/overlays/      страницы источников OBS
tests/                   unit и интеграционные тесты
```

Сервисы переводят сообщения и события в общие типы `ChatMessage` и `StreamEvent`, затем публикуют их в `EventBus`. Очередь алертов, бот, интерактив, OBS-оверлеи и UI подписываются на эту шину.
