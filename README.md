# StreamHelper

StreamHelper — приложение для Windows, которое собирает управление стримом, чат и источники OBS в одном окне. Текущая версия: **0.4.2**. Интерфейс доступен на русском и английском.

## Скачать и начать работу

1. Скачайте `StreamHelper-Setup-0.4.2.exe` на [странице последнего выпуска](https://github.com/Rayness/StreamHelper-Releases/releases/latest) и установите приложение. Установщик Windows сейчас не подписан сертификатом издателя.
2. Откройте **Подключения** и войдите в Twitch как вещатель. Авторизация проходит через код на сайте Twitch. Для отправки сообщений ботом можно отдельно подключить его аккаунт.
3. Если нужен OBS, включите **WebSocket Server** в OBS Studio и подключите его в StreamHelper на странице **Подключения**. По умолчанию используется порт 4455.
4. Откройте **Оверлеи**, выберите источник, настройте его и нажмите **Добавить в OBS**. Кнопка создаст Browser Source в текущей сцене. При желании можно скопировать URL и добавить источник вручную.

Приложение должно работать во время эфира: локальный сервер на `127.0.0.1` отдаёт оверлеи и обновляет их через WebSocket. По умолчанию порт сервера — 4848; его можно изменить в **Настройках**. При закрытии окна StreamHelper может оставаться в системном трее.

### Что где находится

| Раздел | Возможности |
| --- | --- |
| Главная | Состояние эфира, объединённый чат, ответы и модерация, последние события. |
| Оверлеи | Настройка, живой предпросмотр, URL и добавление источников в OBS. |
| Алерты | Тексты, звук, медиа, озвучка, пороги и очередь событий. |
| Интерактив | Колесо, голосование, розыгрыш, босс чата и аниме-квиз. |
| Бот | Команды, таймерные сообщения, счётчики и модерация. |
| OBS и действия | Сцены, запись, эфир, источники, звук, быстрые действия и док-панель. |
| Подключения | Twitch, OBS, донаты, Streamer.bot, Discord и Kawaki. |
| Настройки | Язык, локальный порт, сброс отдельных настроек и обновления. |

`Ctrl+K` открывает палитру команд для быстрого перехода и запуска действий.

## Оверлеи

Все оверлеи работают как отдельные источники браузера OBS. На странице **Оверлеи** рядом с каждым есть рекомендованный размер, предпросмотр и индикатор подключённых источников.

| Источник | Что показывает |
| --- | --- |
| Алерты | Фолловы, подписки, битсы, рейды, донаты и награды. |
| Чат | Сообщения, эмоуты, значки, время, контекст ответа и настраиваемые анимации. Есть подложки «карточка», «стекло», градиент, контур, неон, полосы, реплика и прозрачный стиль; можно добавить свою картинку. |
| Последние события | Компактная лента активности канала. |
| Награды за баллы | Последние пользовательские награды Twitch: зритель, название, стоимость и, при желании, его ответ. |
| Коллаб | Список каналов участников совместного эфира и входящие рейды. Список каналов заполняется вручную. |
| Баннеры | Прежние текстовые баннеры, бегущая строка и расписание показа. |
| Реклама | Готовые изображения и видео партнёров с отдельным расписанием. 14 эффектов появления, включая глитч. Текстовые баннеры работают независимо. |
| Статус эфира и сообщение на экране | Название, игра, зрители, время эфира; отдельный источник для выделенного сообщения чата. |
| Цели, таймеры и лейблы | Прогресс, сабатон, обратный отсчёт, часы и текстовые переменные. |
| Интерактивные источники | Колесо, голосование, розыгрыш, босс, квиз и дождь эмоутов. |
| Kawaki | Что сейчас смотрите: постер, название и прогресс. |

**Баллы канала:** StreamHelper получает событие `channel.channel_points_custom_reward_redemption.add` от Twitch, если у подключённого вещателя доступны пользовательские награды и разрешён доступ `channel:read:redemptions`. Встроенные награды Twitch не попадают в эту ленту. Название награды можно привязать к колесу, удару по боссу или быстрому действию. Если Twitch не предоставляет это событие, оверлей остаётся пустым; остальные функции работают.

**Коллабы:** добавьте Twitch-каналы гостей по одному на строку. Карточка обновляется без перезагрузки OBS. Входящие рейды показываются автоматически, если подключение Twitch передаёт их события. Совместный чат или управление чужими каналами не подключаются автоматически.

## Подключения и автоматизация

| Сервис | Настройка |
| --- | --- |
| Twitch | Вход вещателя через Device Code Flow; отдельный вход для бота при необходимости. Приложение получает чат, события EventSub и сведения об эфире. |
| OBS Studio | Локальный obs-websocket v5. Включите сервер WebSocket в OBS и укажите адрес, порт и пароль в **Подключениях**. |
| DonationAlerts | Авторизуйте аккаунт через приложение. Если встроенный Client ID недоступен, укажите свой в дополнительных настройках. |
| Streamlabs | Вставьте Socket API Token своего аккаунта. |
| StreamElements | Вставьте Channel ID и JWT из панели StreamElements → Account → Channels. Учитываются завершённые разрешённые донаты Astro. |
| Streamer.bot | Включите HTTP Server в Streamer.bot, укажите порт (обычно 7474) в **Подключениях**. Действия можно назначить на быстрые кнопки, хоткеи и награды за баллы. |
| Discord | Создайте webhook текстового канала и вставьте URL. Можно включить анонс эфира и уведомления о донатах; есть тестовая отправка. |
| Kawaki | Войдите через `kawaki.ru/link`. Доступны «сейчас смотрим», команда `!аниме` и шаблон названия эфира. Если данные плеера недоступны, используется последний тайтл из списка «Смотрю». |

Сейчас платформа чата — Twitch. В коде есть интерфейс `ChatPlatform` для будущих подключений YouTube, VK Play Live и Kick, но их рабочие коннекторы ещё не реализованы.

### Док-панель OBS

В StreamHelper откройте **OBS и действия → Док-панель StreamHelper для OBS** и скопируйте адрес. В OBS выберите **Вид → Док-панели → Настраиваемые док-панели браузера**, задайте имя и вставьте URL. Через док можно управлять сценами, эфиром, записью, алертами, интерактивом, рекламой и быстрыми действиями. URL содержит случайный ключ доступа: храните его как пароль и обновите в OBS, если измените порт оверлеев.

## Обновления и данные

Начиная с 0.4.x установленная версия проверяет обновления при запуске и каждые шесть часов. Загрузка идёт в фоне; установку и перезапуск вы запускаете в **Настройках**, когда эфир не прервётся. Файлы обновления публикуются в [публичном репозитории выпусков](https://github.com/Rayness/StreamHelper-Releases/releases). Версии 0.2.0 и старее нужно один раз обновить установщиком вручную.

Данные пользователя находятся в `%APPDATA%\StreamHelper`: `settings.json` содержит настройки, `secrets.bin` — токены, зашифрованные средствами Windows, `media/` — импортированные звуки, изображения и видео. Для переноса настроек закройте приложение и скопируйте эту папку; перенос `secrets.bin` между разными пользователями Windows может потребовать повторного входа в сервисы.

Локальный сервер привязан к `127.0.0.1`. URL док-панели защищён отдельным ключом. Обычные URL оверлеев предназначены для локального OBS: не публикуйте порт сервера в интернет без своей защиты.

## Частые проблемы

- **Пустой оверлей:** проверьте, что StreamHelper открыт, URL источника совпадает с текущим портом и в OBS включено обновление страницы источника. Некоторые источники ждут события или ручного показа.
- **Нет наград за баллы:** войдите как вещатель повторно, чтобы Twitch выдал нужный доступ; проверьте, что в канале есть пользовательская награда. Встроенные награды не поддерживаются.
- **Нет управления OBS:** включите WebSocket Server в OBS и проверьте порт/пароль. StreamHelper управляет только подключённым OBS.
- **Антивирус или SmartScreen предупреждает об установщике:** сборка пока не подписана сертификатом издателя. Сверяйте файл и контрольную сумму с выпуском на GitHub.
- **После смены порта не работает док:** скопируйте новый URL из приложения и замените адрес в настройках док-панели OBS.

## Разработка

Нужны Node.js и npm, Windows для сборки установщика. Исходники — Electron, React и TypeScript.

```powershell
npm install
npm run dev
npm run typecheck
npm test
npm run build
npx electron-builder --win --publish never --config.directories.output=dist/0.4.2
```

Сборка установщика остаётся локальной, пока явно не запущен скрипт публикации. Для выпуска в публичный репозиторий обновлений:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/publish-release.ps1 -ValidateOnly
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/publish-release.ps1
```

Перед выпуском убедитесь, что `package.json`, версия установщика и `latest.yml` совпадают. Скрипт проверяет наличие установщика и blockmap, а также что репозиторий обновлений публичный. Для регистрации своего Twitch-клиента используйте [Twitch Developer Console](https://dev.twitch.tv/console/apps): тип **Public**, OAuth Redirect URL `http://localhost`; Client ID задаётся в приложении или `DEFAULT_TWITCH_CLIENT_ID` в `src/shared/defaults.ts`. Для DonationAlerts создайте клиент с Redirect URI `http://127.0.0.1:4848/auth/donationalerts` и укажите Client ID. Клиентские секреты для этих потоков авторизации приложению не нужны.

### Структура проекта

```text
src/shared/              типы, настройки, значения по умолчанию, шаблоны
src/main/                Electron main process, сервисы и IPC
src/main/platforms/      Twitch и интерфейс платформ чата
src/main/donations/      сервисы донатов
src/main/obs/            управление OBS
src/main/overlay/        локальный HTTP/WebSocket сервер и док-панель
src/main/features/       алерты, интерактив, реклама, статистика и действия
src/renderer/            интерфейс React
resources/overlays/      страницы источников OBS
tests/                   unit и интеграционные тесты
```

Сервисы переводят сообщения и события в общие типы `ChatMessage` и `StreamEvent`, затем публикуют их в `EventBus`. Очередь алертов, бот, интерактив, OBS-оверлеи и UI подписываются на эту шину.
