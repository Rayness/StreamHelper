# StreamHelper 0.14.0

18 октября 2026 · Windows x64

**Студия событий** — новый раздел в боковом меню для сцен донатов, подписок, подарков и рейдов на HTML, CSS и JavaScript. Сцены хранятся отдельно в каждом профиле и работают через существующий источник OBS `/overlay/alerts`.

- **Редактор и превью:** выберите готовую сцену или создайте свою, настройте код, параметры, размеры, длительность и тестовые данные. «Перезапустить» показывает локальный предпросмотр без отправки события в OBS. Ошибки JavaScript видны рядом с превью.
- **Черновик → публикация → привязка:** сохраните черновик, нажмите «Опубликовать», назначьте сцену событиям и включите «Сцены в эфире». Тип события также должен быть включён в настройках алертов. Правки опубликованной сцены сохраняются отдельным связанным черновиком; только явная публикация обновляет эфирную версию. Существующие настройки и прогресс сохраняются, события без назначенной сцены используют обычные алерты.
- **Донаты, подарки и рейды:** уровни донатов выбирают самый высокий подходящий порог в основной валюте, с подтверждённой конвертацией сервиса при её наличии. Близкие подарки одного дарителя можно объединять в одну сцену с общим количеством. Готовые шаблоны включают обычный и крупный донат, распаковку подарочных подписок и встречу рейда с порталом.
- **AI API:** OpenAI Responses, совместимый Chat Completions и Anthropic Messages. Ключ, модель и адрес API задаёт пользователь; для явно заданного локального совместимого сервера ключ необязателен. Системные инструкции задают бренд, палитру и стиль, а служебный контекст объясняет модели данные события и API `scene.*`. Результат сначала открывается как кандидат в превью; применение, сохранение и публикация выполняются отдельно.
- **Локальный MCP:** внешний ИИ-клиент с токеном доступа получает контекст студии и runtime, читает сцены, сохраняет черновики и предлагает локальное превью. Сервер слушает только `127.0.0.1`; инструментов публикации, платежей и управления OBS нет. Исходники сцен, AI-настройки и MCP доступны владельцу в приложении, но не удалённым модераторам.

Установщик `StreamHelper-Setup-0.14.0.exe` не подписан сертификатом издателя. Официальные выпуски: [StreamHelper](https://github.com/Rayness/StreamHelper/releases/tag/v0.14.0) и [репозиторий обновлений](https://github.com/Rayness/StreamHelper-Releases/releases/tag/v0.14.0).

Изолированно проверены TypeScript, сборка, 468 тестов в 38 файлах, 43 редактора модулей, 9 редакторов подключений, 30 случаев геометрии алертов, 18 сценариев удалённого интерфейса и 9 групп сценариев студии. Проверки используют демонстрационные события, тестовый AI-ответ и локальный MCP. Реальные AI-провайдеры, OBS, аккаунты и платежи не проверялись; работа с ними требует отдельной проверки на конфигурации стримера.
