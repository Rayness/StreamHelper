# Проверки StreamHelper 0.13.0

Дата: 18 октября 2026. Сборка Windows x64 из объединённых PR #12 и #13 с исправлениями, внесёнными перед слиянием. OBS, реальные аккаунты и установленная пользовательская копия StreamHelper не запускались.

## Проверки исходников и интерфейса

- `npm run typecheck` — успешно.
- `npm test` — 404 теста в 33 файлах, успешно.
- `npm run test:ui` — производственная сборка и оба набора изолированных проверок Electron, успешно.
- Основной интерфейс: открыты все 43 редактора модулей и 9 редакторов подключений; выполнены 30 проверок геометрии алертов. Проверены очередь заказов с точными идентификаторами треков, настройки TTS, выбор голоса, тестовое сообщение, пропуск и очистка очереди, профили, конструктор, переменные и сетка панели.
- Удалённый интерфейс: 18 сценариев входа, прав, обновления состояния, предпросмотра, отзыва доступа и управления модераторами, без ошибок консоли.
- Регрессионные тесты проверяют смену ключа, блокирование отозванного соединения, закрытие туннелей предпросмотра, проверку Origin, некорректные сообщения и адреса, а также восстановление или паузу Яндекс Музыки до отключения управляющего соединения.

Машинные отчёты: [основной интерфейс](ui-results-0.13.0.json), [удалённый интерфейс](remote-ui-results-0.13.0.json).

## Границы проверки

В UI-проверках TTS используется настоящий сервис очереди с подставленными голосами и синтезатором. Реальная речь Windows, звук и эффекты в OBS, вход в Яндекс и воспроизведение в приложении Яндекс Музыки в этом выпуске не проверялись. Работа удалённого доступа проверена локально; внешние VPN и HTTPS-туннели не использовались.

Установщик Windows не подписан сертификатом издателя. Для удалённого доступа через интернет нужен HTTPS-туннель или защищённая VPN-сеть.
