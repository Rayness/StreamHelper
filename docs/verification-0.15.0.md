# Проверки StreamHelper 0.15.0

Дата: 5 ноября 2026. Проверен PR #14 и исправления ревью. Пользовательская установленная копия приложения и реальные аккаунты не использовались.

## Исходники и интерфейс

- `npm run typecheck` — успешно.
- `npm test` — 484 теста в 39 файлах, успешно.
- `npm run test:ui` и повторная проверка `node scripts/test-ui.cjs` на окончательной сборке — три набора изолированных проверок Electron.
- Основной интерфейс: 44 редактора модулей, 10 подключений, 30 случаев геометрии алертов. В JSON-отчёте сохранились старые статические подписи «9 подключений» и «43 редактора»; фактический цикл проверяет 10 подключений, размер набора редакторов проверяется равным 44.
- Удалённый интерфейс: 18 сценариев. Студия событий: 9 групп сценариев.
- Регрессионные проверки: токен микрофона отсутствует в ответе `app:init` и обновлениях состояния удалённого модератора, при этом сохраняется у владельца; смена языка не запускает новый распознаватель дважды; Unicode-токен отклоняется с HTTP 403 без исключения сравнения буферов.

Машинные отчёты: [интерфейс](ui-results-0.15.0.json), [удалённый интерфейс](remote-ui-results-0.15.0.json), [студия](scene-studio-ui-results-0.15.0.json).

## Границы проверки

Telegram проверен с подставными ответами API, страница микрофона — с подставным распознавателем, маршруты и удалённый доступ — через настоящие локальные HTTP/WebSocket-серверы. Реальные OBS, Twitch, Telegram, YouTube, Яндекс Музыка, микрофон, браузерный перевод, установка поверх пользовательской копии и фактическое автообновление не проверялись.

Установщик не подписан сертификатом издателя, как и предыдущий выпуск.

`npm audit` сообщает 16 уязвимых пакетов (12 moderate, 4 high), включая прежние версии Electron, Vite и зависимости инструментов сборки. PR не меняет версии зависимостей; их обновление не включено в этот выпуск. Полный локальный отчёт: `dist/qa/npm-audit.json`. Успешные тесты не отменяют эти предупреждения.
