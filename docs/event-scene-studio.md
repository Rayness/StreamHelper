# Студия событий StreamHelper

Раздел **Студия событий** доступен в боковом меню и из модуля «Алерты». Студия хранится отдельно в каждом профиле. Она использует существующий источник OBS `/overlay/alerts`: добавлять новый источник для каждой сцены не требуется.

## Создание и включение сцены

1. Выберите готовую сцену: световая карточка доната, крупный донат «Сверхновая», общая распаковка подарочных подписок или встреча рейда «Звёздные врата». Можно начать с пустой сцены.
2. Настройте HTML, CSS и JavaScript в отдельных вкладках. Во вкладке «Настройки» задаются название, тип события, размер, длительность, громкость, параметры JSON, импортированные изображения/звук и инструкции для ИИ.
3. Укажите тестовые имя, сумму, сообщение, количество подарков или зрителей рейда и нажмите «Перезапустить». Это локальный предпросмотр без финансового события и без отправки в OBS. Ошибки JavaScript показываются рядом с превью. Звук предпросмотра выключен по умолчанию.
4. **Сохранить черновик** сохраняет рабочую версию. При редактировании опубликованной сцены создаётся связанный черновик: эфирная версия сохраняется.
5. **Опубликовать** делает выбранную версию доступной для назначения событиям. Опубликованный связанный черновик заменяет исходную версию с сохранением её привязок.
6. В «Привязках» назначьте сцены событиям, добавьте уровни донатов и включите «Сцены в эфире». Сам тип события также должен быть включён в обычных настройках алертов. Для событий без опубликованной совместимой сцены используется прежний алерт.

При уходе с несохранёнными правками редактор спрашивает о переходе и сохраняет возможность восстановления. Внешняя смена профиля сохраняет незавершённую работу для исходного профиля. Черновики, эфирные сцены и привязки разных профилей независимы.

## Уровни донатов, подарки и рейды

Уровень доната содержит название, минимальную сумму и сцену. Выбирается максимальный подходящий порог. Пороги используют основную валюту приложения и конвертированную сумму, только если сервис донатов её предоставил; неподтверждённая конвертация не производится. В самой сцене сохраняются исходные сумма и валюта события.

Для подарков используется агрегированное количество подписок из события Twitch. Дополнительное окно 0–5 секунд объединяет близкие события одного дарителя, источника и уровня подписки в одну сцену. Повтор события с тем же идентификатором не увеличивает количество. Анонимные события разных идентификаторов не объединяются. Данные о получателях не выдумываются: текущая модель сцены содержит дарителя и количество.

Сцена рейда получает название пользователя и число зрителей. Готовый шаблон рисует портал и флот, ограничивая число визуальных элементов. Оформление, текст, время и анимации доступны для редактирования.

## Контракт HTML/CSS/JS

HTML — содержимое сцены, CSS — стили, JS — отдельный выполняемый код. Фон по умолчанию прозрачный. Сцена исполняется в отдельном `sandbox="allow-scripts"` iframe без доступа к Electron preload, Node, API приложения, хранилищу ключей или родительскому DOM. Превью и эфир используют один генератор документа.

```html
<main>
  <h1 data-field="user"></h1>
  <p data-field="message"></p>
  <strong><span data-field="amount"></span> <span data-field="currency"></span></strong>
</main>
```

`data-field` вставляет данные как текст. Не вставляйте сообщения зрителей через `innerHTML` или строковый JavaScript.

В JavaScript доступен `window.scene`:

| Поле / метод | Назначение |
| --- | --- |
| `scene.event` | `id`, `type`, `user`, `amount`, `currency`, `message`, `count`, `viewers`, `months`, `tier`, `anonymous`, `source` |
| `scene.params` | Пользовательские строки, числа и boolean из настроек сцены |
| `scene.preview` | Режим локального предпросмотра |
| `scene.durationMs`, `scene.width`, `scene.height` | Длительность и исходный размер сцены |
| `scene.mediaBaseUrl` | Адрес локального сервера медиа |
| `scene.mediaUrl(filename)` | Абсолютный адрес импортированного файла или ссылки `/media/...` |
| `scene.finish()` | Завершить визуал, остановить его аудио; очередь сохраняет запланированную длительность |
| `scene.onUpdate(callback)` | Подписаться на обновление данных от родителя; возвращает функцию отписки |

Цветовые параметры доступны как CSS-переменные: параметр `accent` → `var(--accent)`. Внешние JS-библиотеки и сетевые запросы из сцены блокируются. Используйте CSS, SVG, canvas и импортированные медиа. Ограничения: 100 сцен на профиль, 200 000 символов на каждый исходник, 60 параметров, длительность 1–120 секунд, размер до 3840×2160. Уровней донатов — до 50.

## Генерация через API

Во вкладке **ИИ + MCP** доступны:

- OpenAI Responses API;
- серверы с совместимым Chat Completions API, включая явно заданный локальный сервер;
- Anthropic Messages API.

Укажите адрес API, точное имя доступной вам модели и ключ. Для локального совместимого сервера ключ необязателен. Для внешнего сервера требуется HTTPS. Ключ хранится в `SecretStore` и не возвращается в настройки, контекст сцены или MCP. Можно сохранить существующий ключ, заменить или удалить его.

Настраиваются системные инструкции, temperature (или отсутствие параметра), максимум токенов и таймаут. В системных инструкциях задайте бренд, палитру, язык, композицию и ограничения анимации. Конкретная сцена дополнительно передаёт свои исходники, параметры, размеры, длительность и инструкции. Служебный контекст автоматически объясняет модели контракт `scene.*`, работу с данными события, прозрачность и формат ответа.

Результат показывается в превью как кандидат. Применение к редактору, сохранение и публикация — отдельные действия. Поздний ответ после смены сцены или профиля не перезаписывает работу. Кнопка отмены прекращает ожидание в редакторе; запрос на стороне провайдера может продолжаться до завершения или таймаута.

## MCP для внешнего ИИ-клиента

Включите локальный MCP-сервер в той же вкладке, выберите порт и скопируйте готовую конфигурацию. Пример структуры:

```json
{
  "mcpServers": {
    "streamhelper": {
      "url": "http://127.0.0.1:4851/mcp",
      "headers": { "Authorization": "Bearer TOKEN_FROM_STREAMHELPER" }
    }
  }
}
```

Сервер слушает только `127.0.0.1`. StreamHelper должен работать. Клиент должен поддерживать MCP Streamable HTTP с заголовками авторизации. Поддерживаемые версии протокола: `2025-11-25`, `2025-06-18`, `2025-03-26`; ответы JSON без SSE-потока.

Инструменты: `scene_context`, `list_scenes`, `get_scene`, `save_scene_draft`, `preview_scene`. Также доступны ресурс `studio://context` и промпт `create_event_scene`. Контекст содержит текущий профиль, язык, валюту, системные инструкции, сцены и описание runtime; ключи аккаунтов и AI-провайдеров в него не входят.

MCP сохраняет черновики. Изменение опубликованной сцены создаёт отдельную ревизию. `preview_scene` присылает сцену в редактор для принятия и локального просмотра, а не запускает алерт в эфире. Инструментов публикации, платежей или управления OBS нет. Обновление токена отключает доступ по старому токену. Редактор исходников, AI-конфигурация и MCP недоступны через удалённый интерфейс модераторов.
