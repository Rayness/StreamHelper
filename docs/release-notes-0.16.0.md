# StreamHelper 0.16.0

21 ноября 2026 · Windows x64

- **DonateX.** Вставьте внешний токен в **Подключения → DonateX**. Новые донаты появляются в ленте, запускают алерты и учитываются в статистике, сабатоне и заказах музыки. В существующих сборах DonateX можно включить в списке источников. Тестовые донаты из кабинета проверяют алерты без изменения сумм.
- **YouTube Music.** В «Сейчас играет» появилась отдельная платформа. Ссылки на треки и плейлисты сохраняют исходный сервис в очереди, избранном и фоновых миксах. OBS воспроизводит треки, доступные для встраивания.
- **Музыка из браузера.** «Сейчас играет» различает YouTube Music, YouTube, Яндекс Музыку и Spotify по данным медиасессии Windows. Если Windows показывает только «Браузер», расширение для Chrome и Edge помогает опознать сайт звучащей вкладки. Откройте **Сейчас играет → Определение вкладки**, чтобы загрузить его и скопировать ссылку подключения.

Установщик `StreamHelper-Setup-0.16.0.exe` без подписи издателя. Контрольные суммы установщика и файлов автообновления есть в `SHA256SUMS.txt`.
