# StreamHelper 0.17.1

22 ноября 2026 · Windows x64

Исправления вёрстки после обновления 0.17.0:

- **Полноэкранный режим на широких мониторах.** Убраны жёсткие ограничения ширины с прижатием влево — на мониторах Full HD, 2K и 4K рабочая область, редакторы модулей, подключения, Конструктор и Студия событий равномерно заполняют всю ширину окна.
- **Выбор шрифта и превью в «Алертах».** Поле «Шрифт» растянуто на полную ширину карточки, чтобы название шрифта не обрезалось, а предпросмотр получил больше места на широких экранах.

Установщик `StreamHelper-Setup-0.17.1.exe` без подписи издателя. Контрольные суммы установщика и файлов автообновления есть в `SHA256SUMS.txt`.
